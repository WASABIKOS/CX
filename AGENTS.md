# Instrucciones del proyecto

Para cualquier tarea relacionada con CX NPS, Excel `CWP*.xlsx`,
`feedback_review.csv`, clasificación de comentarios o dashboards, carga y
sigue [`skills/cx-nps-operacion/SKILL.md`](skills/cx-nps-operacion/SKILL.md).

Ese skill define los archivos editables, la clave `feedback_key`, el flujo
incremental y la ruta del HTML publicado. No subas datos de clientes ni
artefactos generados al repositorio público.
